# Agent Note: 工作区目录浏览器的常用位置快捷入口

Status: implemented

[English](2026-08-13-workspace-directory-quick-access.md) | 中文

## 问题

应用内「选择工作区目录」对话框在宿主账户的主目录打开，只提供两条前进路径：面包屑（始终停留在当前祖先链内）与路径编辑（键入完整路径）。在 Windows 上祖先链止于盘符根，因此到达另一个盘——账户主目录在 `C:\`、而项目在 `D:\` 是常见情形——每次都必须键入完整路径。[目录选择能力 seam](../architecture/2026-07-28-directory-picker-capability-seam.md) 把盘符枚举记为暂无消费方的暂缓事项；多盘 Windows 主机上对话框的日常使用就是这个消费方。

## 决策

浏览交互在 seam 两侧都获得常用位置表面。

**Seam 与协议。** `DirectoryPickerBrowseCapability`（`dsh-host-directory-picker` 的 Service Definition）新增 `listRoots(signal?)`，返回 `DirectoryRoot[]`；新的 `host.listRoots` RPC 在与 `host.listDirectory` 相同的 `browse` 能力门槛与错误映射下（中止 → `cancelled`，类型化失败 → `internal`）把它送到浏览器。每个根是一个机器键加绝对路径——`{ kind, path }`，`kind: 'home' | 'root' | 'drive' | 'desktop' | 'documents' | 'downloads'`——因为展示文案归客户端所有：宿主从不格式化面向用户的标签。

**后端。** `dsh-host-directory-picker-browse` 按展示顺序枚举：主目录，其下实际存在的常规用户文件夹（桌面、文档、下载），然后是平台卷面。Windows 上是每个存在的盘符，经标准 A–Z 表并发探测、每个字母带 400ms 上限——缺失字母以 ENOENT 快速失败，上限只切断真正停滞的探测（断连的映射网络盘会让 SMB 重连挂起整个列表直到 SMB 超时），被切断的盘被丢弃而不是报错。其他平台卷面是文件系统根 `/`。探测函数与平台／主目录事实均可由构造函数注入，使枚举在测试中完全确定；类保持其稳定能力契约（`listRoots` 与其余方法共用同一能力对象）。这正是 seam 依赖调研已认可的纯 stdlib 路线——被否决的 `drivelist` 一类原生插件仍然被否决。

**客户端。** 对话框（`dsh-client-ui-directory-picker-browse`）每次打开通过与其他浏览调用相同的注入通道 `ctx.workspaces.listRoots` 获取一次根列表，关闭即中止、被取代的打开所产生的结果被丢弃（沿用对话框既有的代际守卫）。面包屑栏在 crumb 序列与路径编辑区之间安放**常用位置**菜单：每个根一行，常规种类用本地化标签（主目录、桌面、文档、下载、根目录），盘符显示裸字母（`D:`），配磁盘图标。选中一行即以与面包屑跳转完全相同的方式导航——选择锚定、在展示根之外双栏落地——跨盘或跳到项目文件夹无需键入。触发按钮只在枚举返回后渲染，owner 采纳进行中或嵌套新建对话框打开时禁用，枚举失败则整体撤下（路径编辑仍是兜底），而不是抛出核心导航不需要的错误。

## 备选方案

- **仅路径编辑（维持现状）。** 否决：这正是本特性要解决的缺口——在 Windows 上不键入 `D:\…` 就无法到达另一个盘，而且不知道编辑区存在的用户根本看不到这条路。
- **客户端猜测盘符（试 `D:\`、`E:\`…）。** 否决：硬编码字母表必然出错（没有 `D:`、额外的可移动盘、UNC 共享），并在协议上重复宿主已拥有的平台事实；枚举属于已经掌握 `homedir` 与平台语义的后端。
- **原生盘符枚举依赖（`drivelist`、`windows-drive-letters`）。** 否决：理由同 seam 调研已记录的——健康度与比例——而且没有必要：基于 `fs.stat` 的 A–Z 探测加上逐字母上限纯属 stdlib，绝不挂起对话框。
- **由宿主返回展示字符串。** 否决：桌面／Desktop 属于客户端文案；协议携带机器键、客户端本地化，与对话框内其他宿主标记的展示（`hidden` 标志）采用同一切分。
- **首次打开菜单时才惰性获取。** 否决：它给菜单增加加载态和第二条协议生命周期；根列表与主目录列举一样跟随对话框既有的打开／关闭生命周期，枚举返回后触发按钮自然出现。
- **常驻「此电脑」栏或盘符行列表。** 否决：Miller 视图是目录浏览器而不是 shell；菜单让快捷表面保持一次点击之遥，不改变分栏模型。

## 后果

- 协议新增 `host.listRoots`（请求 `{}`，响应 `{ roots }`）；客户端运行时暴露 `workspaces.listRoots`；连接 fixture 提供确定的根列表，让无密钥的组合测试与对话框 golden 都能覆盖该表面。
- `dsh-host-directory-picker-browse` 与 seam 的 README 中「不枚举盘符根」的限制已删除；seam Agent Note 中的暂缓项现已落地，并在此交叉引用。
- 对话框的 aria golden 新增常用位置触发按钮；常用位置菜单本身纯属展示（无模型可见输入、无会话事件）。
- 探测停滞的盘对菜单不可见，但仍可通过路径编辑器到达；未来后端可在不触碰协议 kind 键的前提下提供每卷标签（卷名、剩余空间）。
